# Genotek Specialized Agents

This folder contains specialized AI agents for different types of construction projects.

## Agent Structure

Each agent is specialized for a specific construction sector:

### 1. **Hospitals Agent** (`hospitals_agent/`)
- Specializes in healthcare facility construction
- Focuses on: Hospitals, clinics, medical centers, healthcare facilities
- Materials: Clean room materials, healthcare-compliant products, sterile environment solutions

### 2. **Shopping Malls Agent** (`shopping_malls_agent/`)
- Specializes in retail and commercial construction
- Focuses on: Shopping malls, retail centers, commercial complexes
- Materials: High-traffic flooring, fire-rated products, commercial finishes

### 3. **Hotels Agent** (`hotels_agent/`)
- Specializes in hospitality construction
- Focuses on: Hotels, resorts, casinos, entertainment facilities
- Materials: Luxury finishes, weather-resistant products, premium materials

### 4. **Residential Agent** (`residential_agent/`)
- Specializes in residential construction
- Focuses on: Apartments, condos, housing developments, mixed-use
- Materials: Sustainable materials, energy-efficient products, residential finishes

### 5. **Airports Agent** (`airports_agent/`)
- Specializes in aviation infrastructure
- Focuses on: Airports, terminals, runways, aviation facilities
- Materials: High-durability materials, fire-rated products, infrastructure solutions

## How Agents Work

Each agent will have:
- Specialized search queries for their sector
- Custom extraction prompts for sector-specific details
- Tailored classification criteria
- Industry-specific email templates
- Sector knowledge base

## Usage

Agents can be run independently or together to cover all construction sectors for Genotek's material supply business.
